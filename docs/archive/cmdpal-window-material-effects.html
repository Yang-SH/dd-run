窗口材质与边框 · 优化方案效果页

v1.0 · 2026-09-13 · 参考 DeskBox「外观 → 窗口材质与边框」能力面（源码取证）

方案四项：P1 材质单选化（两互斥开关 → 无材质/云母/亚克力三段 pill）、P2 不透明度滑杆（0–100%，默认 40 = 真机调定锚点；0 = 纯材质，拉满 = 面板最实）、 P3 窗口圆角三选（圆角/小圆角/方角，DWM 三常量）、P4 面板边框三选（中性/强调色/关）。卡片更名「窗口材质与边框」。 模拟口径声明：本页用 CSS backdrop-filter 近似模拟 DWM SystemBackdrop——云母 ≈ blur(90px)（壁纸柔化采色）、亚克力 ≈ blur(22px)（实时模糊）； 浓淡层 alpha 用规格真值。真机观感以 DWM 渲染为准，壁纸差异会导致同一 alpha 观感不同（这正是「不透明度」设置的存在意义）。 P2 v3 浓淡基色 = 面板色 × 系统强调色（暗 8% / 亮 16%，DeskBox BuildContentTintColor 配方）——S4 的强调色样块会联动全部材质层的色相。

S1 · P1 材质三选（无材质 / 云母 / 亚克力）

同一壁纸上的三档面板。云母与亚克力的差别：采色方式（柔化采样 vs 实时模糊）与 GPU 开销（云母低）。 浓淡层为默认 40% 档（真机对比 DeskBox 调定的推荐观感，cap 按材质两主题同档）：云母 0.30、亚克力 0.40（v5 起亮暗同档）。

S2 · P2 不透明度滑杆（0–100%，默认 40）

滑杆缩放 egui 侧浓淡层（panel_fill 的 alpha），不触碰 DWM 属性——拖动只重注册双主题 Style，零闪烁面。 直控式换算 alpha = cap × pct/100（cap 按材质两主题同档：云母 0.75 / 亚克力 1.0）： 0% = 纯材质，100% = 面板最实（亚克力拉满全实色；云母拉满保留 25% 采色语义）；默认 40% = 真机对比调定推荐观感。拖动试试：

文档语义为「标签页窗口」材质，对无标题栏启动器属误用；三档已覆盖需要。
AcrylicBase（基础亚克力）
DWM 只有一档亚克力，DeskBox 的 Base 是 XAML 层 tint/luminosity 参数模拟；不透明度滑杆覆盖同一需求面。
边框粗细（细/中/粗）
DWMWA_BORDER_COLOR 宽度固定 1px；egui 自绘粗描边在圆角处有对齐缺口风险（platform.rs M2 已记档），启动器收益低。
材质强度第二滑杆
与不透明度语义重叠（DeskBox 双滑杆源于 XAML tint/luminosity 双参数），双滑杆复杂度不值。
Win10 旧版亚克力
accent-policy 路径 + 提示横幅：Win10 已过支持期（2025-10），现有不透明回退稳定且语义清晰。
动画设置
A1 验收要求唤起瞬时，此前已记档不做（DWMWA_TRANSITIONS_FORCEDISABLED 恒禁用）。
