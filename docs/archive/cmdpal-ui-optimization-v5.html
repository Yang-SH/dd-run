B5 · 结果行结构：移除中间的路径/描述列

现状行内三段（标题 → 副标题/路径 → 类型标签）在应用结果里中间一段几乎总是 exe / lnk 路径，挤占标题宽度、拉低扫读效率。优化后行内只保留 图标 + 标题 + 类型标签；被移除的信息不丢——整行悬停时以 tooltip 呈现 （标题全文 + 副标题，两行）。加载骨架行右侧的描述条同步移除，保证 Loading → 内容无布局跳动（A3 口径）。

B7 · 悬停反馈体系（齿轮 / 设置导航项 / 开关）

现状：齿轮与导航项虽画了 row_hover 底，但暗色下与面板底色差小、图标不提亮、 光标不变化，感知上等于没有悬停效果（用户 2026-09-12 反馈）；开关 draw_switch_fn 则完全没有悬停态。优化 = 统一小控件悬停语言： hover = row_hover 底 + 图标/文字 text2→text；按下 = row_pressed， 开关 hover 走 accent_hover（开）/ row_hover（关）。 光标分级：齿轮 / 导航项（导航语义）用 PointingHand，开关 / Fluent 按钮（命令语义） 保持默认箭头（Win32/Fluent 惯例）；选中导航项悬停不铺 row_hover。 新增 accent_hover token（暗 #2886de / 亮 #115ea3，值来自既有设计稿 CSS）， 真机复验原报告，若仍无悬停再定位事件链。 把鼠标放到下面两组控件上对比体验（左 = 现状，右 = 优化后）：

B8 · 面板宽高按显示器工作区自适应

现状：基准恒为 650×440，仅当工作区不足时等比收缩（D37）——在小笔记本上没问题， 但 2K / 4K 竖向空间充裕时面板仍只显示 9 行结果，屏幕利用率低；多显示器（混合分辨率 / 缩放）下换屏唤起已有逐次 clamp。优化（记忆值优先原则不变——用户手动拉伸过就以用户为准）：

小屏 / 768p：9 行（下限）· 452
1080p：11 行 · 532
1440p 及以上：12 行（上限）· 572
规则内容
高度推导（仅无记忆值时） rows = clamp(floor((avail_h − 92) × 0.5 ÷ 40), 9, 12)，面板高 = rows×40 + 92（顶行 52 + 页脚 36 + 边距 4）；宽恒 650。92/40 等常数即现有几何，无新概念
记忆值优先 settings.panel_size 有值时原逻辑不变（基准推导不参与）
设置页联动 沿用现规则 max(650×640, 根页有效尺寸) → 工作区 clamp；根页变高后设置页仍 ≥ 640 高，左栏 168 + 内容区布局不变
多屏 / 缩放验收矩阵 4K + 1080p 双屏各唤起一次（clamp 逐屏生效）；125% / 150% / 200% 缩放（egui 逻辑点自适应，图标 48px 源已覆盖到 240%）；竖屏（宽 clamp 优先）；工作区小于基准（等比收缩 + 460×400 下限）；缩放热切换后再次唤起尺寸正确
不做 逐帧内容自适应高度（结果数驱动窗口 resize 有抖动风险，launcher 以稳定为第一体验）

B2 · 小面积强调色（暗色主题）

现状：暗色下选中指示条与聚焦下划线用 #115ea3（brand[70]，colorBrandBackground 语义）， 在 #292929 面板上对比度仅约 2.2:1，几乎与背景融为一体。 Fluent 2 对小面积元素另有 colorBrandStroke1 语义：暗 = brand[100]、亮 = brand[80]（与现值相同，不受影响）。 新增 --accent-stroke token，仅替换 3px 指示条 / 2px 下划线 / Spinner 弧 / 开关选中 / 设置导航指示条等 线状小元素；大面积 accent 底色（主按钮等）维持 brand[70] 不变。
