2. SHA256 比对：按文件名行解析 SUMS → 与下载文件哈希比对。**决策点（默认零依赖）**：sha256 用紧凑纯函数实现（约 80 行，NIST 标准向量 ×3 + 空串/长串单测锁定，零新增 crate）——若评审倾向审计过的 crate 则改采 `sha2`（+1 依赖，需在冲突矩阵行同步改判）；**默认纯函数**。
3. 校验通过 → `Success` toast「校验通过，解压覆盖即完成更新」+ 打开所在目录（复用既有打开目录路径）；失败 → 删除半截 zip 与 SUMS + `Error` toast（固定 3000ms 口径）。

5. **边界**：不做自替换（承既有决策「便携版静默替换 exe 风险大于收益」）；不做进度条 UI（curl 静默 + 完成态提示）；下载失败清理残留。

- [x] 真机：构造低版本号 → 检测 → 下载 → 校验过 → 目录打开；篡改 zip → 校验失败 + 清理 + Error toast（2026-11-24 A21；v0.2.1 不含 O17，采用同源码临时低版本验收构建（版本常量 `0.2.1` + 自动触发钩子），证据见 walkthrough §7.2 续跑记录 4）
