03

窗口行为与启动修复规格

已确认决策

启动黑框的根因已定位（eframe 0.36 post_rendering 首帧后强制 set_visible(true) → 与我们的 Visible(false) 及启动期 center_on_screen 竞争，形成「左上角黑框 → 跳到中间 → 闪现 → 隐藏」）。 修复采用「初始定位屏幕外 + 唤起时才居中显示」方案（PowerToys Run 同款做法），以下为验收规格：

场景行为验收标准
进程启动 完全静默：窗口物理上不可见（初始位置在屏幕外），无黑框、无跳动 启动全程肉眼不可见任何窗口/闪现；热键唤起前 Visible 从未对用户可见
启动期焦点 窗口创建 with_active(false)：首帧被 eframe 强制可见时也不夺取焦点 启动全程 dd-run 从不成为前台焦点窗口（不打断用户正在进行的输入）
热键唤起 窗口在光标所在屏居中出现并获取焦点（PowerToys Run 行为） 多显示器下每次唤起均居中于 GetCursorPos 所在 monitor；无位置跳动
失焦 自动隐藏（现行逻辑保留，handle_focus_loss 不变） 点击面板外任意处即隐藏
启动期居中 删除现有 recenter_if_needed 启动期逐帧轮询；居中并入 show()， 按 Win32 GetCursorPos + MonitorFromPoint 自算位置—— egui center_on_screen 按窗口当前所在屏取 monitor，屏幕外窗口会取错屏，不可复用 窗口隐藏期间不再发送任何位置命令；居中仅在 show() 内执行
04

图标规范（协议 §8.6 三态 → 本次实现两态）

glyph + path url 留接口

协议已定义三态图标，PanelItem 现将其丢弃（转换处 icon: None）。本次打通 glyph 与 path 两态，url 预留枚举分支但不实现下载/缓存。

形态数据来源渲染方式落点
glyph Icon{type:"glyph", value:"\u{E8C8}"} 图标字体渲染 16–20px 码位；加载顺序 SegoeIcons.ttf（Win11 Fluent Icons）→ segmdl2.ttf（Win10 MDL2 回退，码位兼容） 宿主启动时加载进 egui 字体库（现有 setup_cjk_fonts 扩展）
path Icon{type:"path", value:"C:\\...\\icon.png"} 解码 PNG/ICO → egui 纹理；按路径缓存 textureId，避免每帧重解码；加载失败显示占位 glyph 新增图片解码依赖（image crate，仅启用 png/ico 所需 feature）；验收演示 = dd-ext-sample 增一枚 path 图标项（exe 同目录 demo.png，build.rs 拷贝）
url Icon{type:"url", ...} 本次不实现；渲染层 enum 分支保留，命中时回落占位 glyph —
数据链路：CommandItem.icon（协议已有）→ PanelItem.icon（新增字段）→ 聚合器 flatten 透传 → 渲染层统一 IconView 组件（20px 列）。三种来源都经同一缓存键（glyph 码位 / path 字符串）。 无图标项（icon: None，如兜底项）保留 20px 空列对齐网格，与 ueli 恒定图标列一致。

06

优化项：设置入口 / 结果类型标签 / 上下文页脚

新增 参考 ueli 9.x

依据真机反馈与 ueli 9.x 实际界面追加以下三项： ① 面板左下角常驻设置按钮；② 搜索结果右侧显示类型标签；③ 页脚由「全局源摘要 + 键位图例」改为「上下文动作提示」。 本章节给出 UI 规格、数据流、token 与严格的核对校验表，供后续批次实施参照。

6.1 设置按钮

项规格
位置页脚最左侧，与页脚同高垂直居中；左边缘与页脚左内边距 16px 对齐。
图标Segoe Fluent Icons 齿轮 \u{E713}，字号 16px，颜色 --text-3（#8d8d8d / #979797）。
热区24×24 px（视觉 16px + 8px 可点击扩展），hover 时颜色变为 --text-2，无背景变化。
交互左键点击在同一 eframe 上下文内以子视图/弹出层打开设置（复用现有 PageStack 推入 SettingsPage，或弹 egui::Window）；不新起进程/线程、不引入第二个 wgpu 上下文。设置视图不占用全局热键。
作用域页脚位于应用级 Panel::bottom（draw_panel 内），已覆盖所有页面栈层级（Root View 与嵌套 ListPage），无需额外处理。
键盘可达焦点可 Tab 到按钮，Enter/Space 触发；支持快捷键（待定，建议 Ctrl+,）。

6.2 搜索结果类型标签

项规格
位置每行最右侧，与行同高垂直居中；右边缘距行右内边距 10px。共存次序：类型标签最靠右，.tag chips 紧邻其左（类型比用户自定义 tag 更具结构性）。
内容按通用内容类别显示（应用 / 网页 / 命令 / 设置 / 文件 / 文本 / 音频 / 视频 / 图片 …）；内置扩展按 provider ID（全限定 com.ddrun.*，去 com.ddrun. 前缀后匹配）硬编码映射到类别；第三方扩展未命中时回退「命令」或显示扩展 ID 原文。协议层不改。
映射表（去 com.ddrun. 前缀后） apps → 应用；calc → 命令；system → 设置； websearch → 网页；shell → 命令。 第三方扩展未命中 → 回退「命令」或显示扩展 ID 原文。
注：「文本 / 音频 / 视频 / 图片 / 文件」为类别枚举预留项，供第三方扩展声明；当前 5 个内置扩展仅覆盖 应用 / 设置 / 网页 / 命令 四类。
样式纯文本，字号 12px，颜色 --text-3，右对齐；不占 chip 背景，与 ueli 截图一致。
截断最大宽度 90px；超长时末尾截断并加 …。
数据流 CommandItem（协议）无 kind 字段，dd-protocol 冻结 v1.0 不新增。3.9 计划新增 PanelItem.result_category: Option<String>（存类别显示标签）；GUI 聚合器按 PanelItem.ext_id 去前缀推导后填充 → 渲染层右对齐显示（类型最右、tags 其左）。

6.3 页脚：上下文动作提示（ueli 式）

项规格
常态列表有选中项时，页脚左侧显示当前选中项的默认动作文本，右侧显示该动作的快捷键提示。
示例apps 项 → 左侧 打开应用，右侧键帽 ↵ Enter；websearch 项 → 打开网页 / ↵ Enter；calc 项 → 计算 / ↵ Enter；CommandRef::Page 项 → 进入 / ↵ Enter。
无选中 / 空态显示全局键位图例（↑↓ 选择 / Enter 执行 / Esc 返回/隐藏）。源健康诊断保留但仅异常时显示：当聚合结果中存在 stub/err 源时，在页脚追加 ok/stub/err 状态点（沿用 3.8 的三态点）；常态全 ok 时不显示，避免撑高。
动作来源动词由 CommandRef 决定（Invoke→执行类、Page→进入类），宾语由 ext_id 决定，GUI 层硬编码映射表：apps→打开应用、system→打开设置、shell→运行命令、websearch→打开网页、calc→计算；第三方未命中→执行。映射表需单测覆盖（C7）。
高度严格 35px，padding 9px 16px。绘制约束：必须用 ui.horizontal 强制单行 + ui.set_min_height(35)，禁止 horizontal_wrapped（否则 5 源会撑回 72px）。无选中时仅显示键位图例，高度不变。
底 / 边背景 --panel-2，顶部 1px --border；已落地。
