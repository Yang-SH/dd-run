CmdPal · Design Spec · Rev 3

命令面板 UI 设计稿 / 暗色交互版

依据 cmdpal-platform-agnostic-design.md §4（UI / 页面设计）重绘的 11 个界面（含 Empty / Loading 两态）。全部为真实 DOM + CSS 组件，可直接感知布局、状态与微交互；支持键盘走查（↑↓/Tab 在列表项间移动、Enter 选中、Esc 返回）；Rev 2 起采用暗色极客效率风（Raycast / Linear 路线）。
